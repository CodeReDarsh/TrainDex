# UI font

VCR OSD Mono Regular, from the user-supplied `vcr_osd_mono.zip` (original filename `VCR_OSD_MONO_1.001.ttf`). Used unchanged for both letters and numerals. The supplied archive contains no separate license file. Original archive retained in the user Downloads folder.

This is a single-weight font. Body text uses its native Regular weight; uppercase labels use a restrained CSS emphasis rather than replacing or separately scaling numeric glyphs.
